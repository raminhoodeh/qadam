# Akber 6-Stage Filter

Purpose: preserve Akber's trader-led review process as a repeatable signal integrity gate.

Inputs:

- Proposed signal memo.
- Catalyst evidence.
- Technical/contextual confirmation.
- Risk and invalidation fields.

Outputs:

- Stage-by-stage pass/fail.
- Missing evidence list.
- Escalation note for weak or ambiguous setups.

Boundary: this filter can block weak setups, but it cannot authorize broker writes.
