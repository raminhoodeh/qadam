# CC0 Default-View Delete List

This is the initial removal scope for the dashboard Consolidation Cut. The goal is to remove default-view duplication while preserving audit detail inside Diagnostics.

## Remove Or Relocate From Default View

| Current Surface | CC Destination | Reason |
|---|---|---|
| `#forbidden` Safety Stops panel | Diagnostics drawer | Safety remains in one default safety strip; detailed stops are audit detail. |
| `#communications` Telegram Communications panel | Diagnostics drawer | Telegram delivery state is operational audit detail, not a founder-first default block. |
| `#process-console` Process Console panel | Diagnostics drawer | Process/event stream is diagnostic detail, not a default decision surface. |
| `#governance` Fund Manager comments panel | Diagnostics drawer | Governance remains available, but should not compete with mission-control blocks. |
| Standalone worldview panel | Thinking block | Worldview should appear as one labeled prior inside Thinking, not a separate duplicated panel. |
| Overview debug duplicates | Deleted or folded into six founder blocks | Overview becomes the page itself; no second summary layer. |
| Repeated `<dt>Limits</dt>` rows | Diagnostics or deleted | Authority language moves to one safety strip plus audit detail. |
| Repeated `<dt>Boundary</dt>` rows | Diagnostics or deleted | Same guarantee should not be restated across every founder block. |
| Static placeholders and hardcoded metrics | Replaced by live snapshot values or honest empty states | Avoid contradictions with working live data. |
| Duplicate pipeline renderings | One canonical system map | Founder view keeps the full map, but renders it once. |
